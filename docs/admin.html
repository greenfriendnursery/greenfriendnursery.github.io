নাম, দাম, স্টক ও গাছের ৩টি সাইজ দিন।

প্রতিটি সাইজের আলাদা দাম দিন। তিনটি সারি খালি রাখলে এক দামেই বিক্রি হবে। সাইজ দিলে উপরের দামটাই শুরুর দাম হিসেবে দেখাবে।
ফোন বা কম্পিউটার থেকে ছবি আপলোড করুন — JPEG / PNG / WebP, প্রতিটি সর্বোচ্চ ২০ MB। চাইলে নিচে ছবির URL-ও পেস্ট করতে পারেন।
GitHub ছবি হোস্টিং (ফ্রি)
টোকেন দিলে আপলোড করা ছবি GitHub-এ যাবে (খরচ ₹0, ছোট সাইজে অটো কম্প্রেস)। টোকেন না দিলে Supabase Storage-এ যাবে।
